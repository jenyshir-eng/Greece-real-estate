# Telegram-источники: недвижимость Салоник и Греции

Данные: `data/sources/telegram_channels.csv` (63 записи, проверено 2026-09-28).
`members` и `last_post` взяты с публичных страниц `t.me/<name>` и `t.me/s/<name>`. `hidden` — история постов закрыта для просмотра без входа в Telegram.

## Как искали

| Метод | Объём | Результат |
|---|---|---|
| Поиск по каталогу TGStat (tgstat.com, POST-запросы с CSRF-токеном; каналы и группы; с фильтром страны Greece и без) | 79 запросов на RU/UA/EN/GR | ~330 уникальных каналов; основная часть найденного |
| Перебор возможных имён на t.me (город/регион × недвижимость/аренда/realty/akinita…) | ~4 900 имён | ~70 существующих; последние 2 998 имён дали лишь 2 новых релевантных |
| Обход ссылок и @-упоминаний из постов найденных каналов, до 6 страниц истории | ~1 400 проверенных каналов | 3 новых пограничных результата: поиск насыщен |
| Сайты агентств и справочники (inforugr.com — 53 агентства, profi-gr.com — Салоники, homesoverseas, сайты из поиска) | ~110 сайтов | каналы из экосистемы @svetlana_greece, @realestate_thessaloniki, @discounthous |
| WebSearch | ~25 формулировок | @grekodom, @greece_cyprus, группа «Недвижимость в Греции», @greeceland4 |

## Ограничения покрытия

- **Полноту доказать нельзя.** Глобальный поиск Telegram работает только в приложении с авторизованным аккаунтом, а в этой среде его нет.
- **TGStat** без авторизации отдаёт не больше 30 результатов на запрос. Каталог в основном русскоязычный, греческие каналы в нём почти не представлены: запросы «ακίνητα» и «Θεσσαλονίκη» ничего не нашли.
- **Закрыты или недоступны:** telemetr.io и telegramchannels.me (403), tgstat.ru (403). Google, Bing, DuckDuckGo и Startpage через curl отдают капчу или пустую выдачу. Встроенный WebSearch почти не индексирует t.me.
- **Приватные группы** (вход по приглашению или по заявке) находятся только по опубликованным где-то ссылкам.
- **Греческоязычных каналов** о недвижимости Салоник не найдено ни одним методом. Греческий рынок в Telegram почти не представлен: агентства в основном используют порталы (Spitogatos, XE), Facebook и Viber.
