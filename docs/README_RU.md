# Spiti Radar — как устроен проект

Поиск по объявлениям о недвижимости Салоник и области: сайты агентств, сети агентств, порталы и Telegram-каналы в одном месте. Одна квартира, выставленная на нескольких сайтах, показывается одной карточкой со ссылками на все оригиналы.

**Сайт:** https://radar.jenyshir.com (запасной адрес: https://greece-real-estate.pages.dev)
**Репозиторий:** github.com/jenyshir-eng/Greece-real-estate, ветка `main`
**Telegram-бот:** @Spitiradar_bot

---

## 1. Как это работает каждый день

Дважды в день (10:13 и 18:43 по Афинам) GitHub Actions запускает `scripts/daily_update.sh`, сохраняет новые данные в ветку `main`, и Cloudflare пересобирает сайт (см. раздел 7).

`daily_update.sh` делает по шагам:

| Шаг | Скрипт | Что делает |
|---|---|---|
| 1 | `ingest_portal_alerts.py` | Забирает объявления из писем-уведомлений порталов (Spitogatos, Spiti24, Tospitimou, XE, Indomio, Plot). Письма разбирает Google-скрипт в почте, результат лежит в Google-таблице (опубликована как CSV). |
| 1b | `collect_telegram.py` | Читает публичные Telegram-каналы о недвижимости (список в `data/sources/telegram_channels.csv`). |
| 1c | `collect_remax_listings.py` | Сеть RE/MAX, все офисы: страницы выдачи по Салоникам и пригородам. Ограничение 25 минут, каждый день начинает с другой категории. Объявление, увиденное в выдаче, считается проверенным в этот день; пропавшее из полностью прочитанной категории — снятым. |
| 1c | `collect_ktimatoemporiki.py` | Сеть Ktimatoemporiki: карта сайта и данные со страниц объектов, новые и изменённые, плюс перепроверка 80 старых страниц за запуск. |
| 1d | `collect_xe_profiles.py` | XE.gr: страницы агентств Салоник на xe.gr (разрешены robots.txt) с последними объявлениями каждого агентства; объявления, которых давно не видно на страницах агентств, перепроверяются на своей странице (до 150 за запуск). |
| 2 | `collect_listings.py` | Около 200 сайтов агентств Салоник (реестр: `data/sources/agencies_thessaloniki.csv`). Читает новые и изменённые страницы (до 60 новых в день с сайта) и по очереди перепроверяет известные: каждое объявление примерно раз в 7 дней. Ответ 404/410, переадресация на другую страницу или «продано» — объявление снимается. |
| 3 | `normalize_listings.py` | Приводит всё к одному виду: тип, сделка, цена, м², этаж, район по карте районов, точка на карте. |
| 3 | `refine_districts.py` | Для объявлений, где указан только город (или регион угадан по агентству), открывает страницу и читает место самого объекта: строку под заголовком («Ημαθία, Βέροια, Κέντρο»), поля «Περιοχή/Τοποθεσία», точку на карте страницы. Адрес агентства в шапке и подвале не учитывается. До 1500 страниц в день; где ничего не нашлось — повтор через неделю. |
| 4 | `group_properties.py` | Находит один и тот же объект на разных сайтах и склеивает в одну карточку. Совпадения цены, площади и района мало: нужны ещё признаки (тот же этаж, год постройки, точка на карте рядом, одинаковый заголовок, редкое общее слово вроде улицы и т. п.), а противоречия (разный этаж, год, далёкие точки) склейку запрещают. |
| 4 | `update_report.py` | Сравнивает базу до и после запуска: новые, снятые, подешевевшие и подорожавшие объявления, ошибки источников, время шагов. Ведёт историю цен. |
| 4 | `build_search_page.py` | Собирает страницу поиска (один HTML-файл) из шаблона `web/search_template.html`. Данные в сжатом виде, чтобы страница быстро открывалась на телефоне. |
| 5 | `notify_telegram.py` | Отправляет в Telegram новые объекты и снижения цен по фильтрам из `data/sources/notify_filters.json` и короткий отчёт о запуске. Сообщения режутся по 3900 символов (лимит Telegram 4096), доставка каждого проверяется. |

После коммита в `main` Cloudflare Pages сам пересобирает сайт (команда сборки: `mkdir -p site && python3 scripts/build_search_page.py site/index.html`, папка `site`).

## 3. Правила сбора (из ТЗ, раздел 2)

- Продукт — поисковик по объявлениям: у каждой карточки виден источник и есть ссылка на оригинал.
- Только общедоступные страницы. Не обходим вход, капчу, Cloudflare/Imperva/DataDome и платный доступ.
- Честный User-Agent `SpitiRadar/0.1 (+https://spitiradar.gr/opt-out)`, не меньше 3 секунд между запросами к одному сайту, один обход в сутки.
- Явный запрет для нашего бота в robots.txt — сайт исключается.
- Чужие описания не копируем, полноразмерные фото не храним, телефоны и имена частных лиц не храним.

## 4. Что не собирается напрямую и почему

- **Spitogatos, Spiti24, Tospitimou, Indomio, Plot** закрыты защитой от ботов. Объявления приходят только через письма-уведомления, то есть только новые. Больше сохранённых поисков с рассылкой — больше объявлений.
- **XE** закрывает страницы выдачи для облачных серверов и роботов. Объявления приходят через письма и со страниц агентств на xe.gr (`collect_xe_profiles.py`); на страницах агентств видны только последние объявления каждого агентства.
- Около 125 сайтов агентств закрыты защитой от ботов, около 100 не открываются, у 305 агентств нет своего сайта. Их объекты видны через порталы.
- Green-Acres грузит объявления через адрес, закрытый в robots.txt. Century 21 Greece работает только в Афинах.


## 6. Проверка цен, история и отчёт

- **Дата проверки** показывается отдельно от даты публикации: в карточке «проверено …», в окне объекта — у каждой ссылки на источник своя цена и своя дата проверки.
- Порталы (Spitogatos, Indomio, Plot, Spiti24, Tospitimou) и Telegram не перепроверяются: их страницы закрыты защитой от ботов, данные берутся из уведомлений. У таких ссылок показана дата письма; старше 14 дней — пометка «могло быть уже снято», старше 30 дней объявление уходит из поиска и рассылки.
- **История цен:** `data/listings/price_history.csv` (ссылка, дата, цена). В окне объекта — блок «История», в фильтрах — «цена снижалась».
- **Отчёт о запуске:** `data/listings/update_report.json` (вкладка «Источники»), журнал запусков `data/listings/update_log.csv`, снятые объявления с причиной `data/listings/removed.csv`.
- **Регион в Telegram:** в рассылку попадают только объекты, чьё место подтверждено самим объявлением (заголовок, ссылка, поле места, страница, точка на карте). Объекты, где Салоники предположены лишь по агентству, ждут перепроверки страницы.
- **Доставка в Telegram:** журнал `data/listings/notify_log.csv` (сколько сообщений, сколько доставлено, ошибки). Если сообщение не доставлено, объявления не помечаются отправленными и уйдут в следующий раз.

## 7. Расписание и дежурный

Всё запускает GitHub Actions (`.github/workflows/spiti-radar.yml` → `scripts/ci_run.sh`): репозиторий публичный, это бесплатно и не тратит лимит Claude. Каждый запуск сохраняет данные своего города в `main`, Cloudflare пересобирает сайты. Ручной запуск: GitHub → Actions → Spiti Radar → Run workflow (job: update / watchdog / discover, city: thessaloniki / athens / both).

Сообщения в Telegram отправляет сам сбор: токен бота хранится в секрете репозитория `TELEGRAM_BOT_TOKEN` (Settings → Secrets and variables → Actions), ссылка на таблицу писем — в `PORTAL_ALERTS_CSV_URL`.

| Что | Когда (Афины) |
|---|---|
| Обновление Салоник | 10:13 и 18:43 (отчёт в Telegram сразу после сбора, около 11:30 и 20:00) |
| Обновление Афин | 10:43 и 19:13 |
| Дежурный (`watchdog.py`, оба города): сохранились ли данные, дошёл ли Telegram, обновился ли сайт; если данных нет — предупреждение и повторный запуск | 15:43 и 23:43 |
| Поиск новых агентств (`discover_agencies.py`, оба города) | воскресенье 03:13 |

Время указано по Афинам и не сдвигается при переходе на зимнее время. GitHub иногда стартует задания с опозданием до получаса.

## 8. Запустить вручную

```bash
PORTAL_ALERTS_CSV_URL="<ссылка на CSV таблицы писем>" ./scripts/daily_update.sh
```

Нужен только Python 3, без дополнительных библиотек. Прогон занимает 1–2 часа. Страница появится в `build/spiti-radar-search.html`.

## 9. Афины (второй город)

Афины (Аттика без Пирея) работают на том же коде, что и Салоники, но со своими данными в папке `cities/athens`:
- `cities/athens/data/sources/city.json` — настройки города: 51 район с центрами и русскими названиями, «другие регионы» (Пирей, острова, Салоники…), зоны RE/MAX (100–104, 107), почтовые индексы XE, районы справочника vrisko.gr, адрес сайта, время запусков;
- `cities/athens/data/sources/agencies_attica.csv` — реестр агентств Аттики;
- `cities/athens/scripts` и `cities/athens/web` — ссылки на общие папки, поэтому исправления в коде сразу работают в обоих городах.

Запуск вручную: `cd cities/athens && PORTAL_ALERTS_CSV_URL="…" ./scripts/daily_update.sh`.

Расписание — в разделе 7.

Сайт: athens.jenyshir.com — отдельный проект Cloudflare Pages из того же репозитория, команда сборки
`cd cities/athens && mkdir -p ../../site && python3 scripts/build_search_page.py ../../site/index.html`, папка `site`.
Сообщения в Telegram приходят от того же бота с заголовком «Spiti Radar · Афины».
