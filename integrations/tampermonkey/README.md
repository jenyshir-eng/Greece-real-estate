# Spiti Radar: кнопка для порталов (Tampermonkey)

На страницах Spitogatos, XE, Spiti24, Indomio, Plot и Tospitimou появляется кнопка
«→ Spiti Radar». Нажатие отправляет объявления с открытой страницы результатов
(ссылка, цена, м², этаж, район из карточки) в таблицу alerts. Утренний сбор добавляет
их в поиск и рассылку. Скрипт ничего не листает сам: только то, что открыто у вас.

## Настройка Apps Script (один раз)
1. Откройте проект Apps Script, где стоит `integrations/gmail_alerts/Code.gs`, и вставьте
   новую версию файла. Сохраните.
2. Запустите функцию `setupCapture`. В журнале появится строка `Capture key: ...`,
   скопируйте ключ.
3. «Развернуть» → «Новое развертывание» → тип «Веб-приложение»:
   запуск от моего имени, доступ «Все». Скопируйте URL веб-приложения.
4. Необязательно: «Настройки проекта» → «Свойства скрипта» → добавьте
   `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Тогда бот будет подтверждать каждую отправку.

## Установка скрипта
1. Установите Tampermonkey (Chrome, Edge, Firefox; на Android: Firefox или Edge).
2. Tampermonkey → «Создать новый скрипт» → вставьте `spiti-radar.user.js` → сохраните.
3. Откройте любой портал, нажмите кнопку и введите URL веб-приложения и ключ.
   Поменять их можно в меню Tampermonkey: «Spiti Radar: настройки».

## Использование
Откройте на портале результаты поиска с нужными фильтрами и нажмите «→ Spiti Radar».
Появится «Отправлено в Spiti Radar: N». Объявления без цены не отправляются.
